# UI / Design References Used

This project uses the following libraries as design references and implementation sources where appropriate. It does not bundle third-party source code that is incompatible with the project.

- Vengeance UI: https://www.vengenceui.com/components
- Animate UI: https://animate-ui.com/docs
- Uiverse: https://uiverse.io/
- Uilora: https://www.uilora.com/
- Forget UI: https://www.npmjs.com/package/forget-ui

Notes:
- Vengeance UI is React/Next.js focused and documents open-source components powered by Framer Motion/Tailwind.
- Animate UI is a copy-first React distribution built around Motion and Tailwind.
- Uiverse provides free community UI elements in HTML/CSS/Tailwind/React formats; its Galaxy repository documents MIT licensing.
- Uilora presents a React/Next.js copy-paste component ecosystem and recommends limiting heavy animations per view for performance.
- Forget UI was found to be a legacy Vue 2 component library, so it was not installed into this React 19 project. Its drawer/interaction patterns were considered only where they made sense for the React architecture.
